# Marketplace Seller Performance Optimization (Amazon Marketplace)

**Role:** Product Owner (Agile)  
**Dashboard:** `Amazon_Marketplace_Analytics_Dashboard.pbix` (in `/01_Dashboard`)  
**Goal:** Increase marketplace revenue and profitability by optimizing ad spend, improving listing quality, reducing returns, and preventing stockouts across top ASINs.

## Included (no placeholders)
- Dashboard file
- CSV datasets (`/02_Data_CSV`) tailored to KPI calculations
- SQL validation queries (`/03_SQL/queries.sql`)
- PRD + Backlog + Sprint plan + KPI definitions + RAID + RACI + Release plan (`/04_Docs`)

## Key KPIs
- Gross Revenue
- Net Revenue
- Contribution Margin
- ACoS
- ROAS
- Conversion Rate
- Return Rate
- In-Stock Rate
- Buy Box %
- Average Rating

## Quick start
1) Open the dashboard file  
2) Review `/02_Data_CSV` and `/04_Docs/kpi_definitions.csv`  
3) Run `/03_SQL/queries.sql` to validate KPI logic
