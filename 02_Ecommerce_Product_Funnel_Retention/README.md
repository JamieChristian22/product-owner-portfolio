# E‑commerce Product Funnel & Retention (Web/App)

**Role:** Product Owner (Agile)  
**Dashboard:** `Ecommerce_Product_Analytics.pbix` (in `/01_Dashboard`)  
**Goal:** Improve acquisition→activation→purchase funnel performance and repeat purchase by reducing checkout friction and boosting retention with personalized recommendations.

## Included (no placeholders)
- Dashboard file
- CSV datasets (`/02_Data_CSV`) tailored to KPI calculations
- SQL validation queries (`/03_SQL/queries.sql`)
- PRD + Backlog + Sprint plan + KPI definitions + RAID + RACI + Release plan (`/04_Docs`)

## Key KPIs
- Sessions
- Add-to-Cart Rate
- Checkout Start Rate
- Purchase Conversion
- AOV
- Repeat Purchase Rate (30d)
- Churn (90d)
- CAC (modeled)
- LTV (modeled)

## Quick start
1) Open the dashboard file  
2) Review `/02_Data_CSV` and `/04_Docs/kpi_definitions.csv`  
3) Run `/03_SQL/queries.sql` to validate KPI logic
