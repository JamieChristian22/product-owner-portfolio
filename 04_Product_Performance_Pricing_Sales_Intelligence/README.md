# Product Performance, Pricing & Sales Intelligence (Product Lines)

**Role:** Product Owner (Agile)  
**Dashboard:** `Product Performance & Sales Intelligence Dashboard.twbx` (in `/01_Dashboard`)  
**Goal:** Optimize product mix and pricing using sales intelligence, identifying underperforming SKUs, price elasticity signals, and promotion effectiveness.

## Included (no placeholders)
- Dashboard file
- CSV datasets (`/02_Data_CSV`) tailored to KPI calculations
- SQL validation queries (`/03_SQL/queries.sql`)
- PRD + Backlog + Sprint plan + KPI definitions + RAID + RACI + Release plan (`/04_Docs`)

## Key KPIs
- Revenue
- Units
- Gross Profit
- Margin %
- Price Index
- Promo Lift
- Stockout Lost Sales
- Sell‑through
- Return Rate

## Quick start
1) Open the dashboard file  
2) Review `/02_Data_CSV` and `/04_Docs/kpi_definitions.csv`  
3) Run `/03_SQL/queries.sql` to validate KPI logic
