# Retail Executive KPI & Store Operations (Multi‑Store)

**Role:** Product Owner (Agile)  
**Dashboard:** `Retail Executive KPI Dashboard.twbx` (in `/01_Dashboard`)  
**Goal:** Provide executive visibility into store performance and operational drivers; improve sales per labor hour and reduce shrink while raising NPS.

## Included (no placeholders)
- Dashboard file
- CSV datasets (`/02_Data_CSV`) tailored to KPI calculations
- SQL validation queries (`/03_SQL/queries.sql`)
- PRD + Backlog + Sprint plan + KPI definitions + RAID + RACI + Release plan (`/04_Docs`)

## Key KPIs
- Net Sales
- Gross Margin %
- Sales per Labor Hour
- Foot Traffic
- Conversion (in-store)
- Shrink %
- On‑Shelf Availability
- NPS
- Refund Rate

## Quick start
1) Open the dashboard file  
2) Review `/02_Data_CSV` and `/04_Docs/kpi_definitions.csv`  
3) Run `/03_SQL/queries.sql` to validate KPI logic
