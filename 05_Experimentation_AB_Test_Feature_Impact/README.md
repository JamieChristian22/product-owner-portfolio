# Experimentation: A/B Test Feature Impact (Growth)

**Role:** Product Owner (Agile)  
**Dashboard:** `Experiment _ A-B Test _ Feature Impact Dashboard.twbx` (in `/01_Dashboard`)  
**Goal:** Run a disciplined experimentation program to validate feature impacts while guarding against metric degradation.

## Included (no placeholders)
- Dashboard file
- CSV datasets (`/02_Data_CSV`) tailored to KPI calculations
- SQL validation queries (`/03_SQL/queries.sql`)
- PRD + Backlog + Sprint plan + KPI definitions + RAID + RACI + Release plan (`/04_Docs`)

## Key KPIs
- Primary: Purchase Conversion
- Secondary: AOV
- Guardrails: Refund Rate, Session Latency
- North Star: Weekly Active Buyers

## Quick start
1) Open the dashboard file  
2) Review `/02_Data_CSV` and `/04_Docs/kpi_definitions.csv`  
3) Run `/03_SQL/queries.sql` to validate KPI logic
