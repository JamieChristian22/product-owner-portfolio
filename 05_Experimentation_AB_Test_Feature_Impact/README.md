# 📌 Executive Summary

This project focuses on designing and executing a structured **A/B experimentation framework** to measure feature impact on user engagement and revenue growth.

As Product Owner, I led hypothesis development, experiment prioritization, statistical validation, and rollout strategy to ensure data-backed decision-making.

This case demonstrates **true product experimentation maturity**, not just analytics.

---

# 🎯 Business Objective

Improve growth metrics by:

- Increasing feature adoption  
- Improving user engagement  
- Driving conversion lift  
- Increasing revenue per active user  

---

# 📊 Problem Statement

A new product feature was launched without validated impact on core KPIs.

Leadership needed to determine:

- Does this feature improve engagement?
- Does it increase revenue?
- Is the lift statistically significant?
- Should the feature scale to 100% of users?

Without experimentation discipline, roadmap decisions would rely on assumptions.

---

# 🧠 Experiment Design Framework

### Hypothesis

> Introducing Feature X will increase engagement and conversion due to reduced friction in user workflow.

---

### Experiment Setup

- **Control Group (A):** Existing experience  
- **Test Group (B):** Feature-enabled experience  
- Randomized traffic split (50/50)  
- Minimum sample size threshold applied  
- Duration: 2 weeks  

---

# 📊 Statistical Validation Approach

SQL-based validation included:

- Conversion rate comparison  
- Absolute lift calculation  
- Relative lift percentage  
- Confidence interval estimation  
- Sample size sufficiency check  

Lift was validated before recommending rollout.

---
