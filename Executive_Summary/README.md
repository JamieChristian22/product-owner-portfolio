# 🔍 How I Operate as a Product Owner

## Strategy Alignment
- Translate business goals into measurable outcomes
- Define North Star metric & KPI hierarchy
- Align roadmap to quarterly objectives

## Backlog Ownership
- Prioritize using RICE / MoSCoW frameworks
- Write structured user stories with acceptance criteria
- Decompose initiatives into sprint-ready tasks

## Sprint Execution
- Lead planning & backlog refinement sessions
- Clarify scope before development begins
- Protect sprint focus & manage trade-offs

## Data-Driven Decisions
- Monitor funnel & performance KPIs
- Identify drop-offs & optimization opportunities
- Convert insights into backlog priorities

## Continuous Optimization
- Run A/B experiments & performance tests
- Iterate based on real usage data
- Scale successful features, sunset low-impact work
